# REST API 설계 및 OpenAPI 스펙 작성 규칙

이 문서의 규칙 전문은 스택 무관 공통 규약이므로 `shared/rest-api.md`로 이동했다. 섹션 번호와 제목은 이동 전과 동일하게 유지되어 있으므로, 다른 문서의 "`rest-api.md` N번" 참조는 `shared/rest-api.md`의 같은 번호 섹션을 가리킨다 (예: 3번 HTTP 상태 코드, 8번 OpenAPI 스펙 작성). Spring 프로젝트에서 API 설계·스펙 작성 시 `shared/rest-api.md`를 `api-dto.md`의 spec-first 흐름과 함께 적용한다.
