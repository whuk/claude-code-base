plan.md를 읽고 다음 미완료 테스트(체크 표시가 없는 테스트)를 찾으세요.

1. 테스트 설명을 분석하여 브랜치 유형을 결정하세요:
   - `feature/` : 새로운 기능 구현
   - `fix/` : 버그 수정, 결함 수정
   - `refactor/` : 리팩터링, 구조 개선
   - `test/` : 테스트 추가/수정만 해당
   - `chore/` : 설정, 문서, 빌드 등 기타 작업
2. 테스트 설명을 기반으로 간결한 브랜치명을 생성하세요:
   - 영어 소문자, 단어 구분은 하이픈(`-`) 사용
   - 예: `feature/add-user-login`, `fix/null-pointer-in-parser`
3. 현재 브랜치 상태를 확인하고 `git checkout -b <브랜치명>`으로 브랜치를 생성하세요
4. 생성된 브랜치명과 대상 테스트 설명을 보고하세요

하지 말아야 할 것:
- 여러 테스트를 한꺼번에 대상으로 삼기
- 브랜치명에 한국어나 특수문자 사용하기
- 이미 존재하는 브랜치명과 충돌하기 (충돌 시 숫자 접미사 추가)
